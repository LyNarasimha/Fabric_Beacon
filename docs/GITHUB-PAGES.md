# GitHub Pages (one-time)

If `https://glofoxinc.github.io/Fabric_Beacon/` returns **404**:

1. Open **https://github.com/glofoxinc/Fabric_Beacon/settings/pages**
2. Under **Build and deployment** → **Source**, choose **GitHub Actions** (not “Deploy from a branch”).
3. Push to `main` or run workflow **Deploy GitHub Pages** (Actions tab).
4. After the workflow succeeds, open **DOCUMENTATION.html** at the URL in README.

Canonical team link: **https://glofoxinc.github.io/Fabric_Beacon/DOCUMENTATION.html**
